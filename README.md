# Computational-PDEs

Solving partial differential equations with both classical and machine-learning methods.

This repository collects implementations and experiments spanning three complementary approaches:

- **Classical methods** — traditional numerical schemes for PDEs, such as finite difference, finite element, and finite volume methods.
- **PINNs** — Physics-Informed Neural Networks, where the PDE residual, initial conditions, and boundary conditions are embedded directly into the loss function to approximate solutions.
- **Inverse PINNs** — the inverse formulation, where PINNs are used to infer unknown parameters, coefficients, or source terms of a PDE from observed data.
